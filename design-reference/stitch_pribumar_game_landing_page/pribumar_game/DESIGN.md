## Brand & Style

This design system establishes a high-performance, frictionless gaming commerce interface tailored for fast transactions, instant voucher fulfillment, and digital asset acquisition. It merges the electric immediacy of competitive esports with the trust and operational precision of modern financial technology.

### Aesthetic Foundation
- **Modern Esports Sleek**: Balanced dark mode with obsidian foundations, electric violet energetic flows, and mint-cyan actionable clarity.
- **Precision Glassmorphism**: Controlled translucent surfaces, subtle chromatic perimeter borders (1px), and soft backdrops that avoid cognitive clutter.
- **Commerce Clarity**: High contrast ratios on numerical values, denominations, server verification badges, and payment pathways. Every checkout step prioritizes visual certainty over decorative excess.

## Colors

The color palette pairs intense digital purples with surgical mint-cyan highlights against deep indigo-obsidian surfaces.

### Palette Roles
- **Primary Violet (`#8E1EA2`)**: Drives core interaction targets, promotional highlights, and dynamic energetic states.
- **Secondary Deep Purple (`#542177`)**: Anchors visual mass across navigation framing, structural tiers, and secondary CTA surfaces.
- **Tertiary Magenta (`#D552A3`)**: Designates special offers, premium tier tags, hot deal banners, and flash sale countdowns.
- **Action Cyan / Mint (`#98E8DE`)**: Reserved for verified player status badges, active wallet balances, selection confirmations, and primary purchase completion triggers.
- **Neutral Core (`#0D0B14`, `#161224`, `#1E1833`)**: Deep layered obsidian darks that eliminate eye fatigue while making game banners and denomination items pop.

## Typography

The typography couples the athletic, forward-leaning geometric nature of **Plus Jakarta Sans** for game titles, price tags, and banners with the tabular and functional rigor of **Inter** for descriptions, transaction logs, and game ID inputs.

### Typographic Principles
- **Number Weighting**: Currency amounts (IDR) and diamond counts always use Plus Jakarta Sans Bold or SemiBold to prevent scan errors.
- **Case Rules**: Micro-labels (such as "INSTANT PROCESSED", "FLASH SALE", or "ZONE ID") use uppercase styling with `0.06em` letter spacing for fast, reliable scanning.
- **Hierarchy Control**: Game catalog titles remain bold and assertive; auxiliary transaction receipts maintain strict body sizing to guarantee receipt legibility.

## Layout & Spacing

A 12-column responsive grid on desktop adapts to an 8-column layout on tablet, and a 4-column structure on mobile devices.

### Form Factor Behavior
- **Mobile (<768px)**: 4 columns, `margin-mobile` (16px), and `gutter-mobile` (12px). Denomination grids switch to 2 or 3 columns for quick tap accessibility. Fixed checkout bars dock securely to the bottom viewport.
- **Tablet (768px–1024px)**: 8 columns, `margin-tablet` (24px), and `gutter-tablet` (16px). Catalog layouts scale smoothly into a 3–4 card matrix.
- **Desktop (>1024px)**: 12 columns, max-width of `1280px` centered, `margin-desktop` (40px), and `gutter-desktop` (24px). Split workflows feature catalog selection on the left 8 columns and instant sticky cart checkout on the right 4 columns.

## Elevation & Depth

Visual hierarchy uses tonal surface step-ups supported by colored ambient backdrops and glassmorphism.

### Tier Structure
- **Base Canvas (`#0D0B14`)**: Root application background, flat and non-reflective.
- **Surface Elevation 1 (`#161224`)**: Category containers, payment grouping boards, and table layers. Framed by a 1px border (`rgba(255, 255, 255, 0.05)`).
- **Surface Elevation 2 (`#1E1833`)**: Selectable cards, diamond denomination bundles, and form fields. Includes an ambient glow shadow: `0 8px 24px -4px rgba(14, 11, 20, 0.6)`.
- **Surface Elevation 3 (Floating Modal / Active)**: Sticky checkout summaries and drawer modals. Uses glassmorphism with `backdrop-filter: blur(16px)`, surface fill `rgba(30, 24, 51, 0.85)`, and border highlight `rgba(152, 232, 222, 0.25)`.
- **Interactive Focus Glow**: Active or hovered cards emit a localized violet or mint flare (`box-shadow: 0 0 20px -2px rgba(142, 30, 162, 0.35)` or `0 0 16px -2px rgba(152, 232, 222, 0.3)`).

## Shapes

With `roundedness: 2`, the UI balances clean geometry with tactile friendliness:
- **Base Radius (0.5rem / 8px)**: Input fields, denomination badges, game server selects, and micro buttons.
- **Container Radius (1rem / 16px)**: Top-up item cards, payment method tiles, game title profile cards, and dropdown containers.
- **Hero & Modal Radius (1.5rem / 24px)**: Promo hero banners, checkout flow drawers, and major system dialogs.
- **Full Pill Radius**: Status indicators, category filter chips, and verified server verification tags.

## Components

### Buttons
- **Primary / Checkout CTA**: High-energy gradient from `#8E1EA2` to `#D552A3` or solid Mint `#98E8DE` with dark typography (`#0D0B14`). Rounded to 8px, font `label-action`. Hover initiates a vibrant outer bloom without shifting layout.
- **Secondary**: Tinted dark container `#1E1833` with 1px border in `rgba(152, 232, 222, 0.2)`. Text color `#F7F5FC`. Hover transitions border to full mint-cyan opacity.
- **Quick Denomination Selection**: Square or rectangular card-style buttons showcasing diamond/coin graphic, item count, and price. Selected state triggers a 1.5px `#98E8DE` outline and faint cyan interior glow.

### Input Fields (User ID & Server ID)
- Background `#161224`, border 1px `rgba(255, 255, 255, 0.1)`, text `#F7F5FC`.
- Focused state applies border color `#8E1EA2` and outer shadow `0 0 0 3px rgba(142, 30, 162, 0.25)`.
- Includes integrated inline right-action for instant "Check ID" verification status, turning `#98E8DE` with a checked badge upon successful account validation.

### Game Voucher & Denomination Cards
- Compact, information-dense dark surfaces (`#1E1833`).
- Top-right corner supports mini-badges for bonuses (e.g., "+12 Bonus Diamonds") in `#D552A3` with white micro-typography.
- Active item states project clean esports precision: solid mint border and a high-contrast check indicator.

### Payment Method Cards (QRIS, E-Wallet, Virtual Accounts)
- Horizontal layout displaying payment partner logo on an isolated light neutral pad, payment method title, fee calculation, and real-time processing indicator.
- Disabled or maintenance states clearly gray out with an overlay notice reading "Offline/Maintenance".

### Chips & Category Filters
- Pill-shaped (`rounded-full`), padded 8px 16px.
- Inactive: `#161224` with muted violet text `#B1A9C6`.
- Active: `#8E1EA2` background with `#F7F5FC` text, accompanied by an active indicator pip.

### Checkboxes & Radio Selectors
- Custom 20px controls. Unchecked: `#161224` with 1px outline.
- Checked: `#98E8DE` solid fill with dark `#0D0B14` SVG checkmark or radio dot, ensuring immediate recognition against dark backdrops.
